使い方と変換仕様

CSV → JSON

1行目を項目名（キー）として扱い、2行目以降をJSONオブジェクトの配列に変換します。ダブルクォートで囲まれたセル内のカンマ・改行、2つ重ねた引用符に対応しています。

注意：CSV内の数字・日付・真偽値はすべて文字列のままです。列名の重複や空欄、列数の違いはエラーになります。先頭のBOMは取り除きます。

JSON → CSV

オブジェクトの配列に対応します。列の並びはキーが初めて登場する順番です。欠落した値は空欄になり、ネストされたオブジェクトはJSON形式の文字列として格納します。

JSON整形・圧縮

JSON形式の構文を確認し、インデント付き表示または余分な空白を省いた表示にします。無効なJSONはエラーになります。

URLエンコード・デコード

URLのクエリパラメータ値などに使うパーセントエンコードを実行します。URL全体を変換する機能ではありません。プラス記号を半角スペースに置換するフォーム形式のデコードには対応していません。

セキュリティと制限

  • 入力値はブラウザで処理します。サーバー側変換APIはありません。
  • 読み込めるファイルは5MB以下のUTF-8系テキストを想定しています。Shift_JIS等は事前に文字コードを変換してください。
  • 巨大な入力では端末が遅くなることがあります。
  • 非常に大きな数値はJavaScriptの数値精度の影響を受ける可能性があります。
